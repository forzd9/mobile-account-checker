# وصف أداة فحص الحسابات عبر الهاتف

> **تحذير أمني مهم:** يَظهر من المصدر أن البرنامج يولّد أرقام هاتف وكلمات مرور مرشّحة، ويرسل طلبات تحقق إلى خدمة خارجية، ثم يحفظ الحسابات التي يصنفها صالحة ويرسل بياناتها إلى Telegram. قد يسهّل ذلك تخمين بيانات اعتماد أو الوصول غير المصرح به إلى حسابات، كما قد يؤدي إلى كشف بيانات شخصية. لا تشغّل البرنامج أو تستخدمه على حسابات أو خدمات لا تملكها أو لا تملك تفويضًا صريحًا لاختبارها. هذه الوثيقة لا تمثل موافقة على هذا الاستخدام.

## نبذة

يحتوي المستودع [`forzd9/mobile-account-checker`](https://github.com/forzd9/mobile-account-checker) على ملف Python واحد باسم `بوت لودو.py`. رغم أن الاسم يوحي ببوت للعبة لودو، فإن السلوك الظاهر في المصدر هو إنشاء أرقام هاتف مرشّحة بصيغة تبدأ بـ`05`، وتجربة كلمات مرور مرشّحة عليها عبر واجهة API، وتصنيف بعض الاستجابات، وحفظ بيانات الحسابات التي تُعد صالحة وإرسالها عبر Telegram.

لا يوجد README حالي في المستودع. الوصف أعلاه مستند إلى قراءة ساكنة للملف؛ لم يُشغّل البرنامج ولم يُختبر سلوكه أو اتصاله بالخدمات.

## ما يفعله المصدر

- ينشئ أرقامًا مرشّحة آليًا ويجرب قائمة كلمات مرور معرفة داخل المصدر.
- يرسل طلبات تحقق إلى خدمة خارجية، ويعالج بعض رموز الاستجابة لتصنيف النتائج.
- يستخدم تنفيذًا متوازيًا بعدد عمال مضبوط داخل الملف.
- عند نتيجة يصنفها المصدر على أنها صالحة، يحفظ معلومات الحساب محليًا ويرسل بيانات مرتبطة به إلى محادثة Telegram مضبوطة في المصدر.
- يحتوي على تثبيت تلقائي لبعض الحزم عند استيراد الملف؛ أي إن تشغيله قد يتصل بمستودعات الحزم ويثبت برامج دون خطوة إعداد منفصلة.

هذه أوصاف للسلوك المكتوب وليست ضمانًا لنجاحه أو لصحة تفسيره. لم يتم التحقق من واجهة API أو من استمرارها أو من طريقة قبولها للطلبات.

## المتطلبات والإعداد

لا يتضمن المستودع ملف متطلبات منفصلًا أو إعدادًا موثقًا. يشير المصدر إلى استخدام Python وحزم `requests` و`pycryptodome` و`colorama` و`python-cfonts`، ويحاول تثبيت الحزم الناقصة تلقائيًا. **لا توفّر هذه الوثيقة أوامر تثبيت أو تشغيل** بسبب سلوك تخمين بيانات الدخول والاتصال الخارجي وحفظ بيانات الحسابات، ولأن التشغيل لم يُتحقق منه.

تظهر في المصدر أسماء متغيرات إعدادات مثل `BOT_TOKEN` و`CHAT_ID` و`api` و`PASSWORDS` و`valid_accounts_file` و`THREADS`. وهي أسماء فقط؛ لا توجد آلية إعداد آمنة أو توثيق يثبت دعم متغيرات البيئة، وتبدو بعض الإعدادات والقيم مضمنة في الملف. لا تضع رموزًا أو كلمات مرور أو بيانات جلسات في المستودع أو السجلات. ينبغي إزالة سلوك فحص بيانات الاعتماد وإعادة تصميم المشروع لاختبارات مصرّح بها قبل إعداد أي نسخة قابلة للاستخدام.

## الخصوصية والأمن

وفقًا لمسارات المصدر، قد يتعامل البرنامج مع أرقام الهواتف وكلمات المرور وبيانات الحساب، ويحفظ معلومات في ملف محلي ويرسل بيانات عبر Telegram. لا يوضح المستودع سياسة الاحتفاظ أو الحذف، أو حماية الملف المحلي، أو ضوابط الموافقة، أو حدود الوصول إلى بيانات Telegram. كما أن وضع رموز أو إعدادات حساسة داخل المصدر يعرضها للكشف عند مشاركة المستودع.

لا تستخدم بيانات أشخاص آخرين، ولا ترفع سجلات أو ملفات ناتجة إلى مكان عام. إذا سبق تشغيل نسخة من هذا المصدر أو نشر اعتماد حقيقي فيه، فاعتبره مكشوفًا: ألغِه أو دوّره من الجهة المصدرة، واحذف البيانات الحساسة وفق سياسة المؤسسة والقانون المعمول به. لا تُعد مشاركة أي رموز أو كلمات مرور في البلاغات أو التوثيق.
